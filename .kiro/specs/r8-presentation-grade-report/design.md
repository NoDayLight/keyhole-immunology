# R8 presentation-grade-report design

## Audit before design
A baseline SKCM report was generated and inspected as rendered pixels at 1512 px and 390 px rather than read as source. The recorded defects were one sans face carrying every type role, five decorative section kickers duplicating a nav with no active state, molecular scenes drawing thousands of undifferentiated dots in which the peptide was invisible, a coverage globe encoding percentages as dot radius with labels clipped at the limb, a funnel whose drawn path disagreed with where particles travelled, accessible fallbacks promoted to primary chrome, roughly twelve unsystematic accent hues, and a 560 px minimum canvas that overflowed a 390 px viewport.

## Design system
`resources/web/style.css` owns tokens: near-black surfaces, hairline rules, one accent, three verdict colours used nowhere else, and three font stacks. IBM Plex Serif 400 sets prose and figure captions, the installed monospace sets every number, sequence, allele, and truth label, and the installed UI sans is limited to controls. A numbered rail replaces both the kickers and the pill nav; `main.js` drives its active state from an `IntersectionObserver`.

## Figure anatomy
`resources/web/figure.js` builds caption, persistent truth label, viewport, controls, legend, live status, and exact-value disclosure, and also owns one shared reduced-motion watcher and a small selection store so a candidate choice moves both the funnel and the coverage section. Every module builds SVG and DOM through its helpers; no module builds live markup from a string.

## Vendored runtime
`keyhole.vendor` resolves four byte-exact upstream files, verifies a recorded SHA-256 for each on every render, and adapts the two that use module syntax. three.js `0.169.0` is the last release whose minified ES module is a single self-contained file with no imports, so it inlines verbatim into one inline module element; its namespace is published by a generated bridge parsed from the distribution's single trailing export clause for an explicit symbol allow-list. cobe's one leading and one trailing module statement are replaced by anchored, fail-loud transformations while the file on disk stays byte-exact; phenomenon ships a UMD build needing no adaptation. IBM Plex Serif Latin1 subsets embed as base64 with no `local()` source, which requires `font-src data:` as the single CSP relaxation. Provenance lives in `resources/vendor/PROVENANCE.md`.

## Molecular renderer
`molecule3d.js` reuses the reviewed parser, chain selection, and truth label from `scene.js`, then builds a scene graph with hemisphere, three directional, and ambient lights, ACES filmic tone mapping, and sRGB output. Atom spheres are `InstancedMesh` groups over one shared `IcosahedronGeometry`; bonds are `InstancedMesh` over one shared `CylinderGeometry`. The default hybrid representation draws each chain as a tube through a Catmull-Rom curve fitted to measured Cα positions and draws only the displayed peptide as ball-and-stick, because the peptide is the subject of the report. A second representation draws every packaged display-chain atom. Bond lines are disclosed per figure as a drawing choice from packaged connectivity or same-chain adjacent-residue distance within 1.9 Å through a deterministic spatial hash. Camera framing is the only invented quantity and is documented as such. Quality tiers derive from atom count and device pixel ratio, followed by one measured downgrade reported in the visible status line. `KEYHOLE.molecule.mount` probes WebGL, releases the probe context, and on failure delegates to the untouched Canvas 2D engine while naming the fallback.

## Coverage and charts
`globe.js` wraps cobe with markers driven only by serialized cohort values, editorial centroid anchors documented as not measured locations, and rendering gated on visibility and settled to a static frame under reduced motion, because cobe otherwise drives an uninterruptible frame loop. `charts.js` reimplements the composable structure and visual grammar of the Bklit UI radar chart and the EvilCharts Recharts bar chart as accessible SVG, because both upstreams are React libraries that cannot run in a build-free single file; their decorative hatched variant is repurposed so hatched means heuristic approximation and solid means measured-data model output. The candidate radar is an evidence profile whose axis domains are printed, whose stopped and unreached gates are marked from reason codes, and whose `gateEvidence` builder contains no relational operator at all.

## Gates
Acceptance runs the full test suite, Ruff, JavaScript syntax for every packaged module, `git diff --check`, and full `keyhole validate`, then proves fixed-epoch SKCM `results.json` byte-identical to the R7 oracle and the fixed-epoch report byte-identical across runs. Rendered behaviour is verified in a scripted browser at 1512 px and 390 px, with and without reduced motion, and with WebGL disabled, asserting no console error, zero non-local requests, no document overflow, one persistent truth label per figure, and complete teardown.
